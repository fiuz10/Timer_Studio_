# Timer_Studio_
Massimizza la concentrazione con questo Timer 3D. Un'elegante UI in glassmorphism unita a un ambiente interattivo in Three.js. Personalizza i tempi di focus e pausa, scegli la forma dell'oggetto centrale e ruota la visuale in 3D. Il salvataggio locale tiene traccia delle tue sessioni per mantenere sempre alta la produttività.
